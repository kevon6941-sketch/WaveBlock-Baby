# WaveBlock Baby v3.1 World Build

這版不是「背景圖＋按鈕」。海港環境、消波塊寶寶、NPC、動物、FX、HUD 分層獨立。

## 已實作
- 獨立可移動消波塊寶寶
- 獨立釣客／工人／海巡／海龜
- 五個海港互動區
- 多階段釣魚：移動→釣客靠近→拋竿→等待→咬餌→收竿→結果→回位
- 抗浪與可見裂縫／嚴重破損
- 輕傷砂漿修補
- 重傷模板→灌漿→養護→拆模
- 材料消耗、狀態、日夜、本機自動存檔
