# WaveBlock Baby v3.0 Visual Complete

手機優先的海港大世界養成遊戲。主畫面已改為海港世界，不再使用黃色電子機外框。

## GitHub Pages
將本資料夾內 `index.html`、`css/`、`js/`、`assets/` 一起覆蓋到既有 `WaveBlock-Baby` repository 根目錄，Commit 後 Push 到 `main`。Pages 維持 `main / (root)`。

## 玩法
餵食、清潔、釣魚、抗浪、修補、睡眠、倉庫、狀態；可點擊釣魚碼頭、海洋市集、消波堤、海巡站與吊車區。狀態自動儲存在瀏覽器 localStorage。
